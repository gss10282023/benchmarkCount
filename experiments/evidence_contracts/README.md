# Evidence Contracts Placeholder

This directory is the contract workspace required before evidence scoring.

Subdirectories:

- `drafts/`: LLM-proposed contracts before human review.
- `drafts_repaired/`: mechanically normalized draft contracts for human review; these are still not human reviewed or locked.
- `reviewed/`: human-edited contracts before final lock.
- `locked/`: locked native-aligned contracts allowed for scoring.
- `superseded/`: versioned contracts replaced by later locked versions.

No actual case-unit contracts are generated by the paper-mapping step. Every real contract must be produced from official task/evaluator/schema sources and then human reviewed before scoring.

Required blocker:

- Every P0 main case unit must have one locked native-aligned contract before scoring.
- Lock time must be earlier than first scoring time.
- Unsupported native-aligned requirements must be removed or labeled `stronger_measurement` and reported separately.
- The drafter must not see agent identity, agent trace, native score, outcome label, alternate view verdicts, evidence label, or UNRESOLVE reason.

Use `contract_template.yaml` as the minimum field template.

Strict workflow:

```bash
python3 scripts/draft_contracts.py --manifest experiments/experiment_manifest.yaml --source-bundle official_sources.json --write-templates --call-llm
python3 scripts/repair_draft_contracts.py --input experiments/evidence_contracts/drafts --out experiments/evidence_contracts/drafts_repaired --overwrite
python3 scripts/review_contracts.py --input experiments/evidence_contracts/drafts_repaired --start --reviewer-id REVIEWER --overwrite
# Human reviewers edit the reviewed JSON files.
python3 scripts/review_contracts.py --input experiments/evidence_contracts/reviewed --finish --reviewer-id REVIEWER --review-action "checked source hierarchy and edited unsupported requirements" --overwrite
python3 scripts/lock_contracts.py --reviewed experiments/evidence_contracts/reviewed --reviewer-id REVIEWER --locked-by REVIEWER
python3 scripts/validate_contracts.py --manifest experiments/experiment_manifest.yaml --contracts experiments/evidence_contracts/locked
```
