## Strict case-source support-pointer gate

For every support pointer, the path before `::` must be exactly one of:

- `case_packet.md`, or
- a path printed verbatim under the case packet's `## Source Inventory` heading.

Never cite drafter workspace files such as `draft_instructions.md`, `template.yaml`, `output_schema.json`, or `draft_body.json`. Do not invent paths, use absolute paths or URLs, add a leading `./`, or use `..` traversal. A Source Inventory path is valid only when copied exactly.
